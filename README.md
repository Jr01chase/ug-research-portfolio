# ug-research-portfolio
A collection of my undergraduate projects, experiments and notes for postgraduate recommendation review.


## 实验：OpenCode 本地编译部署
本项目尝试在 Windows 平台本地编译部署 OpenCode。
- 操作：克隆仓库、使用 Bun 安装依赖，排查包管理器、启动脚本等问题，成功拉起前端交互界面。
- 结果：界面可正常打开，但AI能力依赖官方云端接口，免费额度仅限官网网页端，本地客户端无法调用模型。
- 收获：掌握 Bun 工程环境搭建、package.json 脚本排查，理解开源项目前后端分离与云端服务限制。

> 项目价值：完整复现从源码到部署的全流程，锻炼工程排错能力。
>
> ## 实验：OpenCode 桌面端部署
- 操作：下载OpenCode桌面客户端，在Windows平台完成安装，启动客户端并进行C语言代码实验。
- 结果：桌面客户端成功启动，能够正常编辑、编译和运行C语言代码，完成`pow()`函数测试。
- 收获：掌握OpenCode桌面端的基础使用，练习C语言代码编写、编译与调试，体会一体化代码工具的工作流程。
> 项目价值：完成OpenCode桌面客户端部署，基于该环境开展C语言编程实验，锻炼代码调试与验证能力。
